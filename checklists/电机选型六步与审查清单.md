## 六步决策树

1. **先问负载，不先问电机**：最高转速 / 最大扭矩 / 加减速（峰值扭矩）、传动比、占空比。需求没量化，后面全是猜。
2. **定电机类型，按最坏工况选**：有刷 / 无刷 / 步进 / 异步。平时工况人人都会算，决定生死的是堵转、急停、最低速、最高温。
   - 堵转电流口径分类型：有刷直流堵转可达额定 5–10 倍（ULN2003 这类 500mA 驱动阵列推电机是经典惨案）；无刷 / FOC 系统电流上限是控制器限流给的，套不上这个倍数。
3. **定有感 / 无感，算反电动势的账**：最低工作转速下反电动势够观测器用 → 无感省钱；不够 → 霍尔或编码器。零速要大力矩还想无感，只剩高频注入：仅对内置式（IPMSM）有效，且要更高的采样带宽和信号处理链。
4. **定电参数，峰值说了算**：驱动 MOS、采样电阻、过流保护阈值全部按峰值电流 + 占空比倒推，额定只做参考。
5. **定带宽与算力，从电气频率往下推**：电气频率 = 转速 × 极对数 ÷ 60；采样取电气频率 10–20 倍起步；PWM 频率权衡电流纹波与开关损耗；带宽定了 MCU 才好定。
6. **定量产与成本**：EMC、散热余量、降额、第二供应商在选型阶段进账。自己开发 ≠ 省钱，工业 / 物联网驱动等级别混用。

## 表一：需求 → 指标转化表

| 需求原话 | 得先问清 | 落到纸上的指标 |
|---|---|---|
| 转得快就行 | 最高转速多少？持续还是冲刺？ | 额定转速 + 峰值转速 |
| 有劲就行 | 最大负载多少？加减速多狠？ | 连续扭矩 + 峰值扭矩 |
| 精度高一点 | 定位误差容忍多少？要不要反馈？ | 分辨率 + 重复精度 |
| 寿命长一点 | 用在哪？一天跑多久？维护窗口多大？ | 轴承等级 + 维护周期 |
| 成本压一压 | BOM 上限和年用量多大？ | 成本档位 + 供货策略 |

用法：评审会上挨行过，哪一行问不出数，哪一行就是需求漏洞，先补需求再谈方案。

## 表二：量产前选型审查清单

- [ ] 最坏工况过了没有：堵转、急停、最低速、最高温，一项项过
- [ ] 峰值电流和占空比算过散热没有；保护阈值是不是按峰值设的
- [ ] 最低转速下反电动势够不够观测器用，无感方案有没有退路
- [ ] EMC、降额、第二供应商，有没有着落
