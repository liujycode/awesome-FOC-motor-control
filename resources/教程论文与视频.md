# 教程、论文与视频

> 按技能层（L0–L6）分类，每条标了【入门】或【进阶】。别收藏，按你当前所在的层取用——往上的内容先存着，层没到看了也挂不住。

## L0 物理直觉

- **Microchip FOC 教程：Reference Frames and the Illusion of DC Quantities**【入门】
  https://developerhelp.microchip.com/xwiki/bin/view/applications/motors/control-algorithms/bldc/foc/
  把坐标变换讲成"DC 量的错觉"：变换本身不产生扭矩，只是让你能用控直流的方式控扭矩。L0 建立直觉最好的官方短文。

- **PMD：Field Oriented Control (FOC) - A Deep Dive**【入门】
  https://www.pmdcorp.com/resources/type/articles/get/field-oriented-control-foc-a-deep-dive-article
  从六步换向讲到正弦换相再到 FOC，配图讲 D/Q 轴；文章里有同一套 24V 设置六步 17,895 RPM vs FOC 29,310 RPM 的实测对比。

- **GreatScott! / ElectroBOOM 无刷电机与电力电子科普**（YouTube 搜频道名即可）【入门】
  建立"磁场拖着转子走"的物理画面，不碰公式。

## L1 功率级

- **TI Precision Labs：BLDC 电机课程**【入门，有中文版】
  https://www.ti.com.cn/zh-cn/video/series/precision-labs/ti-precision-labs-brushless-dc-motors.html
  BLDC 9 集 + 电机驱动器设计 5 集，免费，官方出品。入门期只认一套体系时，这套加 SimpleFOC 足够走到 L3。

- **TI E2E 官方 FAQ：Debugging Common Issues in BLDC Motor Drivers**【进阶】
  https://e2e.ti.com/support/motor-drivers-group/motor-drivers/f/motor-drivers-forum/1176539/faq-quick-guide-to-debugging-common-issues-in-bldc-motor-drivers
  MOSFET 直通、死区、GVDD 跌落、振铃——功率级的"语言"全在这篇 FAQ 里。炸管排查从这读起。（网页有反爬，浏览器直接打开）

- **ST 六步无感固件调参与排查（wiki 专题）**【进阶】
  https://wiki.st.com/stm32mcu/wiki/STM32MotorControl:6-step_-_Optimization_and_troubleshooting_of_sensor-less_firmware_parameters
  六步换相调参流程文档化程度最高的官方资料之一，配 [UM3259 PDF](https://www.st.com/resource/en/user_manual/um3259-stm32-motor-control-sdk--6step-firmware-sensorless-parameter-optimization-stmicroelectronics.pdf)。

## L2 测量

- **SimpleFOC 文档站**【入门，中文】
  https://docs.simplefoc.com
  电流采样、编码器、驱动板接线都有按步骤的页面，中文文档维护得不错。

- **The Engineering Mindset 示波器教程**（YouTube 搜频道名 + oscilloscope）【入门】
  触发、耦合、时基电压档讲得最通俗的系列。记住一句话：触发就是告诉示波器"什么时候开始抓波形"，这比学按键重要。

- **EEVblog 示波器与测量系列**（YouTube，Dave Jones）【进阶】
  探头补偿、接地弹簧、带宽限制、纹波测量——"万用表给结论，示波器给过程"的各种实例。

- **SimpleFOC 社区论坛真实调试帖**【进阶】
  https://community.simplefoc.com
  重点看带完整参数的翻车帖，比如 48V/23A、极对数 23 的轮毂电机"风镐式剧烈振动"帖，排查焦点就是低边电流采样对齐和死区——全是 L2 的功夫。

## L3 FOC 电流环

- **SimpleFOC 库 + JOSS 论文**【入门】
  仓库 https://github.com/simplefoc/Arduino-FOC ｜论文 https://askuric.github.io/files/paper.pdf
  JOSS, 2022, 7(74):4232。库是最好的入门脚手架，论文适合引用和快速了解设计取舍。注意验收标准是**关掉库手敲一遍**。

- **Tim Wescott：PID Without a PhD**（2000）【入门→进阶，长读】
  https://www.wescottdesign.com/articles/Sampling/pidwophd.html
  二十多年了还在被转发。核心就一句：绝大多数应用 PID 就够了，问题从来不在算法选型。电流环 PI 整定的思路（被控对象近似一阶 RL、零极点对消、延迟吃相位裕度）这篇都讲到了。

- **慧驱动：手把手教你驱动永磁同步电机（60 讲）**【入门→进阶，中文】
  https://space.bilibili.com/622438218/lists/717
  B 站系列课，2020 年起更新，从 Clarke/Park 一路到无感观测器/卡尔曼，配 MATLAB 和代码。中文体系课里最完整的一套。看一节当晚就在自己板子上复现现象，否则等于没看。

- **bldc_foc（论文级精简实现）**【进阶】
  https://github.com/MiloszAdamek/bldc_foc
  STM32G474，电流环 10kHz / 速度环 1kHz / PWM 20kHz。手敲 FOC 时拿来对照，代码量小、结构干净。

- **厂商应用笔记（进阶期换一手资料）**【进阶】
  - TI：InstaSPIN-FOC 用户指南 [SPRUHJ1I](https://www.ti.com/lit/ug/spruhj1i/spruhj1i.pdf)（FAST 观测器 + SpinTAC）
  - ST：X-CUBE-MCSDK（Motor Pilot / CubeMonitor 图形化调参），[中文产品页](https://www.st.com.cn/zh-cn/embedded-software/x-cube-mcsdk.html)
  - Microchip：[motorBench 自动生成 FOC 代码 + AN 系列](https://www.microchip.com/en-us/solutions/technologies/motor-control-and-drive/motor-control-products/dspic33-digital-signal-controllers)，AN1292（PLL 无感 + 弱磁）官方工程在 [GitHub mcsk-an1292](https://github.com/microchip-pic-avr-solutions/mcsk-an1292-dspic33ck256mp508)
  - NXP：[AN12235](https://www.nxp.jp/docs/en/application-note/AN12235.pdf)（双电阻无感 + MCAT/FreeMASTER，电流环 100µs/速度环 1ms）
  - Infineon：[AN240575](https://www.infineon.com/assets/row/public/documents/30/42/infineon-an240575-pmsm-foc-using-xmc7200-mcu-applicationnotes-en.pdf)（XMC7200 PMSM FOC，2024-11）；iMOTION MCE 把 FOC 做成固件引擎
  - 一篇 AN 里通常有完整控制框图、参数推导和故障排查表，是被严重低估的富矿

- **Phil's Lab（YouTube / phils-lab.net）**【进阶】
  https://www.phils-lab.net/
  STM32 PMSM 控制系列 + 控制板 PCB layout + DSP/数字滤波实战，配套 GitHub 开源工程。

- **Biricha Digital**【进阶】
  https://biricha.com/articles/psudf-cs/
  数字电源控制环出身，电流/电压采样与补偿器设计（2p2z/3p3z、Bode 图实测）。电流环整定和电源控制环同源，这块资料很少有人讲。

## L4 速度 / 位置环

- **ODrive 文档：tuning 章节**【进阶】
  https://docs.odriverobotics.com/
  三环带宽嵌套（速度环比电流环慢 5–10 倍、位置环纯 P）、惯量比经验值（1–5 优秀 / 5–10 可接受 / >10 参数压不住）、负载惯量按 J_L/N² 经减速机反射，都在文档和调参指南里。

- **mjbots 博客**【进阶】
  https://blog.mjbots.com/
  moteus 作者的长文，如《Optimizing fast movements》这类控制环整定、热设计、编码器校准文章，全是交付视角的调参方法论。

## L5 无感观测器

- **Microchip AN1078：Sensorless Field Oriented Control of PMSM Motors**（DS01078A）【进阶】
  https://www.microchip.com/en-us/solutions/technologies/motor-control-and-drive/motor-control-algorithms
  2007 年的滑模无感 FOC 经典教材（注意：AN1078 是 **Microchip** 的文档号，不是 ST 的）。配套 tuning guide 在官网可搜到 "AN1078 Tuning Guide"。

- **TI InstaSPIN-FOC（FAST 观测器）**【进阶】
  见 SPRUHJ1I（L3 条目中链接）。无感 FOC 商用化的标杆，盲启动 + 切换流程值得照着读一遍。

- **NXP AN14454：单电阻无感 FOC（S32M244）**（2024-10）【进阶】
  https://www.nxp.jp/docs/en/application-note/AN14454.pdf
  Luenberger 观测器做单电阻无感，近年厂商方案主线（单电阻采样 + 高集成）的代表。

- **Microchip AN1292：PLL 无感 + 弱磁**【进阶】
  dsPIC 电机控制页（L3 条目中链接）可找到 PDF 与官方 GitHub 工程。

先记住物理边界再看算法：反电动势和转速成正比，**零速时反电动势为零，观测器没有信息源**。谁跟你说零速无感高精度，让他先解释信息从哪来。凸极性高频注入（HFI）是另一条路，但只对 Ld≠Lq 的内置式电机有效，且注入信号有可闻噪音。

## L6 工程交付

- **VESC CHANGELOG + issue 区**【进阶】
  https://github.com/vedderb/bldc/blob/master/CHANGELOG.md
  读二十个量产相关 issue（温升、EMC、批次离散），比任何教材都直接。

- **ST UM3259**【进阶】
  见 L1 条目中 PDF 链接。故障排查表部分对 L6 同样适用。

- **MathWorks PMSM_FOC Simulink 例程**【入门，仿真】
  https://github.com/mathworks/PMSM_FOC
  理解算法的好梯子。但仿真里没有死区、没有运放失调、没有温度漂移——那三样正是 L2 和 L6 的全部考点，梯子不能当楼。
